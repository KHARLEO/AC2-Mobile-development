# Receitas App

Aplicativo simples feito com React Native e Expo para consultar receitas usando a API TheMealDB.

## Como executar

1. Instale o Node.js.
2. Abra a pasta do projeto no terminal.
3. Execute `npm install`.
4. Execute `npx expo start`.
5. Leia o QR Code com o Expo Go ou use as opções exibidas no terminal.

## O que o aplicativo faz

- Busca receitas de frango na API TheMealDB usando Axios.
- Mostra nome e imagem das receitas em uma lista (`FlatList`).
- Ao tocar em uma receita, abre a tela de detalhes com imagem, nome, categoria, origem e modo de preparo.

## API

https://www.themealdb.com/api/json/v1/1/search.php?s=chicken
